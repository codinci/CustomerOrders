# CustomerOrders

A GraphQL API for recording customers and the orders they place. Money is an
exact `Decimal` serialized as a string, never a float.

**Status:** Phase 0. State lives in memory and is lost when the server stops.
A SQL Server store is planned for a later phase.

## Requirements

- Go 1.24 or later
- gcc, only if you run the race detector on Windows (`CGO_ENABLED=1`)

## Run the server

```bash
go run ./cmd/server
```

The server listens on `:8080`. Set `PORT` to change it:

```bash
PORT=9000 go run ./cmd/server
```

- GraphQL playground: http://localhost:8080/
- GraphQL endpoint: `POST http://localhost:8080/query`

## Example requests

Create a customer, then place an order for them:

```graphql
mutation {
  createCustomer(input: { name: "Ada Lovelace", phoneNumber: "+15550100" }) {
    id
  }
}
```

```graphql
mutation($in: PlaceOrderInput!) {
  placeOrder(input: $in) { id product quantity price createdAt }
}
```

with variables:

```json
{
  "in": {
    "customerID": "<id from createCustomer>",
    "product": "Widget",
    "quantity": 3,
    "price": "19.99"
  }
}
```

Read back:

```graphql
{
  customers { id name phoneNumber }
  orders { id product quantity price createdAt }
}
```

Notes:
- `price` must be a string such as `"19.99"`. A JSON number is rejected.
- `quantity` must be greater than zero, and `price` must not be negative.
- `customerID` must refer to an existing customer.
- `Customer.orders` and `Order.customer` are not implemented yet.

## Test

```bash
go test ./... -count=1
CGO_ENABLED=1 go test ./... -race -count=1   # race detector; needs gcc on Windows
go vet ./...
gofmt -l internal cmd                        # should print nothing
```

## Layout

| Path | Contents |
|------|----------|
| `cmd/server/main.go` | HTTP wiring: `/query` and the playground at `/` |
| `internal/graph/schema.graphqls` | GraphQL schema, the source of truth |
| `internal/graph/schema.resolvers.go` | Resolver implementations |
| `internal/graph/resolver.go` | In-memory state and its lock |
| `internal/graph/generated.go` | Generated by gqlgen. Do not edit by hand. |
| `internal/graph/scalar/decimal.go` | The `Decimal` scalar |
| `gqlgen.yml` | gqlgen configuration |

## Regenerate code after a schema change

Edit `internal/graph/schema.graphqls`, then:

```bash
go generate ./internal/graph/...
```

This regenerates `generated.go`, the models, and any new resolver stubs.
Hand-written resolver bodies in `schema.resolvers.go` are kept.
